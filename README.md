# Personal Introduction Program

## Project Overview
This project collects user information and displays a welcome message.

## Features
- User Input
- Variables
- Strings
- Print Statements
- f-Strings

## How to Run

1. Install Python
2. Open Terminal
3. Run:

python personal_intro.py

## Sample Output

Hello Mallikarjun!
You are 20 years old from Solapur.

- Python Basics
- Variables
- Input and Output
- String Formatting
